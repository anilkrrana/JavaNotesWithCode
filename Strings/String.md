STRING COMPARISON In JAVA

-> The following are the different ways to compare strings:
1. Using String.equals() Method
2. Using == Operator
3. Using String.compareTo() Method
4. Using startsWith() and endsWith() Methods

#CompareTo() Method:

S1==S2: return 0
S1>S2 : 1 (positive value)
S1<S2 : -1 (negative value)

String Concatenation in JAVA

-> String concatenation is a basic and commonly used operation that allows us to combine two or more strings into a single Strings.

-> Some of the ways to perform string concatenation are:

1. Using + Operator (String Concatenation operator)
2. Using concat() Method
3. using the StringBuilder or StringBuffer Class
4. Using join() Method
5. using Joining() Method
6. Using String.format() Method
